# Explorer Rescue v0.2.7 构建说明

## 推荐

Windows 11 + Visual Studio 2026 / MSVC x64。

直接运行：

```text
构建_VisualStudio.bat
```

脚本通过 vswhere 找到最新 C++ 工具链并输出：

```text
build\ExplorerRescue.exe
```

## 链接设计

正式版：

- `/SUBSYSTEM:WINDOWS`
- `/ENTRY:ExplorerRescueEntry`
- `/NODEFAULTLIB`
- `/MACHINE:X64`

仅链接 Windows 系统库：

```text
kernel32.lib
user32.lib
ole32.lib
oleaut32.lib
shell32.lib
```

## 图标

源码内已带：

```text
src\resources\ExplorerRescue.ico
src\resources\ExplorerRescue.res
```

`.res` 已包含应用图标和 DPI/Windows 兼容 Manifest，并在链接阶段直接嵌入 EXE。


## v0.2.7 新增 USER32 API

窗口位置修复新增 `GetWindowRect`、`SetWindowPos`、`ShowWindow`。均来自 USER32.dll，不增加新的 DLL 依赖。
